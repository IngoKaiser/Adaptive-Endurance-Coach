# Initial 8-Week Endurance Build Framework

This is a starting framework, not a fixed calendar. Running and outdoor cycling can replace planned sessions when they deliver a similar stimulus. Before scheduling, inspect the previous 2-4 weeks across all endurance sports.

The default week should usually contain about three purposeful endurance sessions, with no more than two hard sessions across cycling + running.

| Week | Quality stimulus | Easy aerobic | Third stimulus |
|---|---|---|---|
| 1 | Bike Sweet Spot 3 x 8 min @ ~90% FTP OR controlled run quality | 50-70 min easy Z2 | 75-90 min easy endurance |
| 2 | Bike Sweet Spot 3 x 10 min @ 90-92% FTP | 50-70 min easy | VO2 bike 5 x 3 min OR running intervals if recent run history supports them |
| 3 | Bike Sweet Spot 2 x 15 min @ 92-95% FTP | 50-70 min easy | 90-105 min endurance, indoor or outdoor |
| 4 | Deload: short sub-threshold work | 45-60 min easy | 60-75 min easy |
| 5 | Bike Sweet Spot 3 x 12 min @ ~92% FTP | 60-75 min easy | VO2 bike 5 x 4 min OR controlled hard run |
| 6 | Bike Threshold 2 x 15 min @ ~95-98% FTP | 50-70 min easy | 100-120 min endurance |
| 7 | Bike Over-Unders around threshold | 45-60 min easy | VO2 bike 5 x 3 min OR run quality, not both |
| 8 | Taper / reduced load | 40-50 min easy | FTP reassessment if appropriate |

Rules:

- Do not schedule a hard bike workout solely because the template says so if a hard run or outdoor ride already supplied that week's stimulus.
- Count outdoor endurance rides when duration/intensity match the plan.
- Prefer consistency over catching up missed sessions.
- The live Intervals.icu calendar always overrides this framework once training is scheduled or adapted.
