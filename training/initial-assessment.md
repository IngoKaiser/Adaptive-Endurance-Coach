# Initial Assessment and Baseline

The coach should treat this as a baseline process, not a one-day test battery.

## Current known baseline

- Cycling FTP should come from the athlete's current Intervals.icu setting or a recent deliberate test.
- Resting HR, max HR, HRV and running threshold HR must not be guessed.
- Running and outdoor cycling count toward total endurance load and intensity distribution.

## First 1-3 weeks

1. Complete the one-time upstream activity propagation checks in `docs/data-flow.md`.
2. Read completed running, indoor-cycling and outdoor-cycling activities from Intervals.icu.
3. Use available Intervals.icu wellness/context data and user-supplied Garmin observations to establish resting HR and HRV trends.
4. Do not require a standalone maximal-HR test merely to start training.
5. If Garmin has a credible detected max HR or running lactate-threshold HR from recent quality sessions, use it as an observed value and note its source.
6. Prefer power for structured cycling intensity when FTP is current; use HR/RPE as complementary checks.
7. For running, use pace, HR, RPE and detected threshold information together rather than importing cycling zones.

## Reassessment

Reassess cycling FTP after a training block or when completed workouts and power curves strongly suggest the current value is stale. Never change athlete settings without explicit user authorization.
